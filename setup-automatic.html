FIRST-TIME SETUP

Automatic setup

Connect your cloud Supabase project. The temporary local companion handles privileged setup and forgets its credentials when finished.

Start the trusted setup companion

Run this command from your downloaded release on your own computer, then open the local address it prints. 

npm ci
node --experimental-strip-types tools/setup-companion.mjs

For Local Supabase or manual installation, use the existing setup guide.

Manual setup

Connect Supabase

Credentials are sent only to this local companion and Supabase. They are not saved in browser storage or project files.

Use a dedicated project and a token with project, database, Auth configuration, Edge Function and secret read/write permissions.

Initialize database

Install the current schema, or add missing objects in a compatible partial installation. Existing rows are kept. Incompatible schemas and initialized applications are not overwritten.

Create first administrator

The account is created in Supabase Authentication and confirmed directly. An existing account requires its current password.

Configure Edge Function secrets

Configure RSVP_SITE_ORIGIN and RSVP_SITE_URL for the website address. Supabase provides its platform credentials automatically. No third-party secret is required by the current application.

Deploy Edge Functions

Deploy and verify guest-gateway and admin-invitations from this release. Other functions are left alone. Existing conflicting JWT settings require review instead of being silently changed.

Application configuration

Configure the website URL, administrator invitation redirect and Data API schemas. Keep the event unpublished and retain existing settings.

Verify installation

Check schema, administrator permissions, secrets, function configuration and protected runtime responses before marking setup complete.

Setup complete

The application is initialized. The event remains unpublished.

Download the public browser configuration for your hosting installation. Only the project URL and public key are included. For GitHub Pages, set the existing Actions connection variables and redeploy.

Continue to administrator login

Continuing configures this browser for sign-in. Publish the public configuration to configure the website for other devices.
