New database instructions
  1. Create a cloud Supabase project

  2. In the cloud project’s Security options, choose:

    • Enable Data API: ON

      Required for the website and Edge Function database calls.

    • Automatically expose new tables: OFF

      The installer grants only the access this application needs.

    • Enable automatic RLS: ON

      Keep this protection enabled. The installer also enables RLS and supplies the application policies.

    Keep public in the Data API exposed schemas. Do not expose app_private.

  3. Open its SQL Editor and run the complete downloaded installer once on the empty application schema.
  4. Create and verify the first administrator’s Auth account under Authentication → Users.
  1. Start your local Supabase stack. If the CLI already installed the current baseline, skip the SQL installation.
  2. Open local Supabase Studio
  3. If the application schema is empty, open SQL Editor and run the complete downloaded installer once.
  4. Use the API URL and public browser key printed by supabase status.
